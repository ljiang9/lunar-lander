# lunar-lander 登月舱

终端登月舱物理小游戏：重力 + 主/侧推力 + 燃料管理，把登月舱温柔地放到着陆平台上。纯 Python 标准库。

## 玩法

- 每行输入指令后回车：`w`=主推力、`a`=左推、`d`=右推，可组合（如 `wad`）；空行=滑行；`q`=退出
- 着陆平台在 `x=40±5m`；安全着陆要求：落在平台上、`|vy|≤2.5m/s`、`|vx|≤2.0m/s`
- 燃料只有 100，烧完就只能滑翔了

## 用法

```bash
python3 -m lunar_lander            # 交互游玩（需要终端）
python3 -m lunar_lander --auto     # 自动演示（简单 PID 式控制器）
python3 -m lunar_lander --auto --seed 42 -v
```

## 真实验证

- `py_compile` 通过
- 8 项单元测试全过：重力加速、主推力抵消重力、燃料消耗量精确、高速着陆坠毁、温柔着陆成功、偏离平台坠毁、燃料耗尽后推力无效、侧推力
- `--auto` 在 seed 1/2/3/4/5/7/42 下全部成功着陆，剩余燃料 86–89，真实运行输出如上
- 修过的 bug：单元测试 5 的脚手架把 y 设得太高、一步落不到地面（测试问题，代码无误），已修正

## 已知局限

- 控制器很简单：按高度定目标下降速度、按距离定目标水平速度，无风扰建模也无最优燃料规划
- 交互是"每行一个命令"的回合制，不是实时游戏
- 无存档、无最高分、无难度分级；Python 3.10+
